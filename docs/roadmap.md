### R2 翻译术语滚动记忆（dict + 命中过滤注入）
- 来源：2026-10-04 用户提出：翻译开始时维护空记忆，每批翻完提取关键信息滚动积累，作为后续批次补充 prompt（VideoLingo 术语库的在线滚动变体；优于快照式之处：用模型实际采用的译法做锚）
- 内容：顺序批次循环中维护术语 dict（first-wins，`setdefault` 语义，key 最小长度下限防误匹配）；每批翻完后提取实体类词条；后续批次注入时按当前批源文本命中过滤。错误固化不设干预机制（模型缺陷不买单），数组落盘日志仅作排查
- 验收要点：
  - [ ] 同一术语跨批次译法一致（第二次出现起命中注入）
  - [ ] 注入 prompt 只含当前批命中的词条，不随记忆增长膨胀
  - [ ] 提取失败静默跳过，不阻断主翻译流程
- 依赖：无
