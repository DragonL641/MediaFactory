## Now

### R2 术语表：用户 dict 文件 + 滚动记忆（doing）
- 来源：2026-10-04 用户提出批次翻译后滚动积累术语（VideoLingo 术语库的在线滚动变体）；同日两点修正：① 只提取重要专名控制 dict 增长，判定用纯逻辑（setdefault 冲突检测）而非 LLM 对照；② 恢复 custom_instructions，形式为任务级 JSON dict 文件
- 内容：
  - 种子层：翻译任务可选 JSON 术语文件（`{"源词": "译法"}`）作为 dict 初始内容，先于翻译加载——first-wins 时序天然保证用户词条优先，无独立优先级机制；用户文件永不写回，LLM 滚动补充只进内存 dict（运行结束落日志）
  - 动态层：批次循环维护术语 dict（first-wins，key 统一小写归一化 + 最小长度下限；value 携带 source 标记 user/auto，仅用于日志分级——用户词条冲突记 warning「注入失效信号」，LLM 词条冲突记 debug「正常波动」）；每批翻完后由 LLM 自判「值得记忆」的词条（判据：预计反复出现 + 译法易分歧；每批硬上限 5 条），普通词与一次性概念不入典；提取调用不带历史 dict（成本恒定），判重在代码层过滤后 `setdefault` 入典；检出译法冲突时该批译文按 dict 后处理替换
  - 注入：同一 dict 按当前批源文本命中过滤，经 batch.md 的 `${custom_instructions}` 槽位注入（R1 保留槽位的兑现）
- 验收要点：
  - [ ] 用户 dict 文件词条在翻译中强制生效
  - [ ] 同一术语跨批次译法一致（第二次出现起命中注入）
  - [ ] 注入 prompt 只含当前批命中词条；提取调用成本不随 dict 增长
  - [ ] 提取失败静默跳过，不阻断主翻译流程
- 依赖：无
